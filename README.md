# AFL Game Day Board

A premium web application for planning team rotations, tracking match statistics, recording injuries, and managing player notes for AFL games.

## Hosting
This application is hosted on GitHub Pages and runs entirely in the browser.

## Features
- **Interactive Board**: Drag and drop player tokens directly onto the field.
- **Rotation Manager**: Schedule rotations and swap players between the bench and field.
- **Live Match Stats**: View automatic on-field time percentages per quarter.
- **Injury Logs & Medical Profiles**: Track cumulative injuries and flag reoccurring issues.
- **Save/Load Session**: Match stats are auto-saved locally and can be exported as JSON files.
